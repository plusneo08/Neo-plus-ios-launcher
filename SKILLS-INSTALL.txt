SAY TO THE ASSISTANT
  install the skills from github.com/anthropics/skills     -> lists the skills in that repo
  install the pdf skill from anthropics/skills              -> downloads + checks it, then it waits for your OK (notification: Install / Skip)
  install all skills from github.com/owner/repo
  install skill https://example.com/SKILL.md   (or a link to a .zip, or a file such as /storage/emulated/0/Download/x.zip)
  update my skills | list my skills | turn off the pdf skill | remove the pdf skill

HOW IT WORKS
  1. Install: the files are downloaded and scanned (words about passwords, PINs, payments, "ignore previous instructions",
     shell commands ...). Warnings are shown in the notification. NOTHING is installed until you tap Install.
     The AI model cannot approve it: the approval key is stored with the waiting item and the model never sees it.
  2. Only each skill's name + description is added to the assistant's instructions (about one line each).
  3. When a request matches a skill the assistant calls skill_use, reads the full SKILL.md (and any listed file) and follows it.
     Loading a skill counts as reading outside text: for 2 minutes risky actions (calendar changes, connectors ...) ask you first.
  4. Skills never override the safety rules (no payments, no PINs/OTPs/passwords, no personal details).

LIMITS
  - Scripts are NOT installed (a "scripts" folder, or any file that is not plain text). The assistant cannot run them, so a skill that
    depends on scripts only works as far as its written instructions go.
  - Up to 10 skills per request, 30 files / 600 KB per skill, 40 skills in total. Only https. GitHub's free limit is about 60 requests/hour.
  - Plain-text skills added with "add a skill for calls: ..." work as before (short text, a scope: messages / calls / assistant / all).
  - Installed skills are used in the assistant chat and in the voice calls with the assistant. They are not added to the instructions
    for answering callers or messages for you (that stays the old text skills with a scope).
